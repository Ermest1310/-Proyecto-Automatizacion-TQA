# Proyecto Automatización TQA

Proyecto de automatización de pruebas para la asignatura de **Testing y Quality Assurance (TQA)**.

## Propósito

Aplicar técnicas de automatización de pruebas de software para verificar el correcto funcionamiento de una aplicación: diseño de casos de prueba automatizados, ejecución de suites de pruebas y análisis de resultados, con el objetivo de mejorar la eficiencia y cobertura de las pruebas respecto al testing manual.

## Estructura

El proyecto contendrá el código de las pruebas automatizadas, los datos de prueba y la documentación correspondiente.

## Tecnologías

Por definir según los requerimientos del proyecto.
